install nodejs, mongodb (including MongodbCompass for GUI)
----------------------------------------------------------------------------------
commands needed for setting up express and mongodb
npm install express
npm install mongodb
npm install mongoose
npm install cors
npm install dotenv
npm install nodemailer
------------------------------------------------------------------------------------
IMPORTANT INFO
-------------------------------

=> nodemailer library consistently works with outlook email ids (not any other email service provider), make sure to change the email and password (which is set to NULL) in the ".env" file...

=> if one wants to change the subject/body of the email sent to the user, it can be done by editing lines 20 and 21 of the send_mail.js file 

------------------------------------------------------------------------------------
RUNNING THE APPLICATION
-------------------------------
to run the application, run "start.bat"

wait for the form to open up

now its ready to work!!
